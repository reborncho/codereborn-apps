re:Browser 개인정보 처리방침

시행일: 2026년 10월 28일 · 제공자: codere:born

re:Browser(이하 "앱")는 사용자의 개인정보를 수집하지 않습니다. 앱은 회원 가입이나 로그인이 없고, 개발자가 운영하는 서버도 없으며, 광고·분석·추적 도구를 사용하지 않습니다.

1. 수집하는 정보

개발자는 어떠한 개인정보도 수집·저장·전송하지 않습니다.

2. 기기 안에만 저장되는 정보

아래 정보는 브라우저 기능을 위해 사용자의 기기 안에만 저장되며, 개발자에게 전송되지 않습니다. 앱을 삭제하거나 설정에서 지우면 함께 삭제됩니다.

  • 방문 기록, 북마크·즐겨찾기, 읽기 목록, 열린 탭, 최근 검색어
  • 쿠키, 캐시 등 웹사이트 데이터
  • 앱 설정, 사이트별 설정(확대/축소, 콘텐츠 차단기 사용 여부, 가린 항목 등)
  • 다운로드한 파일, 시작 페이지 배경 사진, 사이트 아이콘 캐시

비공개 탭에서는 방문 기록을 남기지 않습니다.

3. 웹사이트 및 검색 서비스와의 통신

앱은 웹 브라우저이므로, 사용자가 방문하는 웹사이트에 직접 연결합니다. 이 과정에서 해당 웹사이트는 각자의 정책에 따라 정보를 처리할 수 있으며, 이는 각 웹사이트의 개인정보 처리방침을 따릅니다.

  • 검색어 제안: 설정에서 "검색 엔진 제안"이 켜져 있으면, 주소창에 입력하는 글자가 사용자가 선택한 검색 엔진(Google, NAVER, Daum, Bing, DuckDuckGo 중 하나)의 검색어 제안 서비스로 전송됩니다. 설정에서 끌 수 있습니다.
  • 사이트 아이콘: 즐겨찾기 등에 아이콘을 표시하기 위해 해당 웹사이트에서 직접 아이콘을 받아옵니다. 외부 아이콘 서비스에 방문 주소를 보내지 않습니다.
  • 광고·추적 차단: 차단 규칙은 앱에 포함되어 있으며 기기 안에서 적용됩니다. 차단 과정에서 방문 정보를 외부로 보내지 않습니다.

4. 기기 권한

앱은 아래 권한을 사용자가 허용한 경우에만, 해당 기능에 한해 사용합니다.

  • 카메라·마이크: 웹사이트가 화상 통화, 사진 업로드, 녹음을 요청할 때
  • 위치: 웹사이트가 현재 위치를 요청할 때
  • 음성 인식: 주소창 음성 검색. 기기에서 처리할 수 있으면 기기 안에서만 처리하며, 그렇지 않은 경우 Apple의 음성 인식 서비스가 사용될 수 있습니다(Apple 개인정보 처리방침 적용).
  • Face ID: 비공개 탭 잠금 해제. 생체 정보는 Apple 시스템이 처리하며 앱은 접근하지 않습니다.
  • 사진 보관함(추가): 웹페이지 이미지를 사진 앱에 저장할 때

권한은 iPhone의 설정 > 앱 > re:Browser에서 언제든 변경할 수 있습니다.

5. 기기 안의 요약 기능

Apple Intelligence를 지원하는 기기에서 제공하는 글 요약은 기기 안에서 처리되며, 개발자에게 전송되지 않습니다.

6. 아동의 개인정보

앱은 개인정보를 수집하지 않으므로 아동의 개인정보도 수집하지 않습니다.
